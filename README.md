# ⚡ Bengaluru Bolt — feedback

**Bengaluru Bolt** is a free endless runner through Namma Bengaluru. Play it in your browser: **https://bolt.mysterylabs.in**

This repository is only for feedback. There's no game code here.

## How to reach us

- 🐞 **Found a bug?** [Report a bug](../../issues/new?template=bug.yml)
- 💡 **Have an idea?** (a new runner, neighbourhood, power-up…) [Suggest an idea](../../issues/new?template=idea.yml)
- 🗑️ **Want your data removed?** (leaderboard name/score or cloud save) [Request data deletion](../../issues/new?template=data-request.yml)

Before opening a new issue, please search the [existing issues](../../issues?q=is%3Aissue) — someone may have reported it already.

## Please don't post

- Email addresses, phone numbers or other personal information (issues are public)
- Step-by-step exploits or cheat codes — report the bug briefly and we'll follow up
